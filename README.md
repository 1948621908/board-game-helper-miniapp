# 桌游助手微信小程序

这是一个面向桌游聚会的原生小程序，包含：

- 聚会工具首页（掷骰子、指尖选择）
- 掷骰子：可选 1～12 颗、点按页面投掷、滚动动画、点数合计
- 指尖选择：多人同时按住屏幕显示位置圈，人数稳定后随机锁定一个手指
- 投掷记录：保存在本机微信小程序存储中，最近保留 100 条
- 记录页和我的页
- 带图标的底部 TabBar、全局主题色和卡片样式

## 导入

1. 打开微信开发者工具，选择「导入项目」。
2. 选择本目录 `outputs/wechat-tool-miniapp`。
3. AppID 先使用「测试号」或替换 `project.config.json` 中的 `appid`。
4. 从 `pages/home/home.js` 开始替换工具列表和业务逻辑。

## 目录

- `app.*`：全局配置
- `pages/home`：聚会工具首页
- `pages/dice`：掷骰子
- `pages/finger`：多人指尖选择
- `pages/history`：投掷记录
- `pages/profile`：个人设置
